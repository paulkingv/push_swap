DESCRIPTION:
LIBFT is a library composed of different functions from libc, functions 
from different unofficial user extended libc libraries, and functions 
that manipulate/utilize linked lists.

INSTRUCTIONS:

Run [make] to compile the library and generate libft.a. 

Use [make bonus] to include bonus functions. 

Link libft.a with your project when compiling.
